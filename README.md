# CTPG Media Server

Static media server and Bootstrap 5 design system for Cruise & Theme Park Guide.

This repo builds and serves shared front-end assets from:

https://media.cruiseandthemeparkguide.com

## What This Includes

- Extended Bootstrap 5
- Custom spacing utilities from 1–100
- CTPG global styles
- CTPG brand styles
- Global JavaScript
- Optimized public images

## Build Locally

```bash
npm install
npm run build
