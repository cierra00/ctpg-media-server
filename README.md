# CTPG Media Server

Static asset build system for Cruise & Theme Park Guide.

This project compiles a custom Bootstrap-based design system, bundles global JavaScript, and copies public assets into a deployable `dist/` folder for Netlify.

Production URL:

https://media.cruiseandthemeparkguide.com

## What You Built

- Custom Bootstrap 5 pipeline
- Extended utility scales (`1` through `100`) for spacing, opacity, percentages, and z-index
- Project-level global styles and brand styles
- Minified JavaScript bundle
- Static public asset publishing

## Project Structure

```text
media-server/
	netlify.toml
	package.json
	public/
		images/
	src/
		js/
			main.js
		scss/
			main.scss
			brand/
				_tokens.scss
				_brand.scss
			core/
				_bootstrap.scss
				_bootstrap-extended-maps.scss
				_global.scss
	dist/  (generated by build)
```

## Install

```bash
npm install
```

## Build

```bash
npm run build
```

This runs:

- `clean`: removes `dist/`
- `copy:assets`: copies `public/**/*` into `dist/`
- `build:css`: compiles and minifies Sass into `dist/css/ctpg-bootstrap.min.css`
- `build:js`: minifies JS into `dist/js/ctpg-main.min.js`

## Watch CSS During Development

```bash
npm run watch:css
```

## Netlify

Configured in `netlify.toml`:

- Build command: `npm run build`
- Publish directory: `dist`
