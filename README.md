# CTPG Media Server

Static asset build system for Cruise & Theme Park Guide.

This project compiles a custom Bootstrap-based design system, bundles global JavaScript, and copies public assets into a deployable `dist/` folder for Cloudflare R2.

Production URL:

https://media.cruiseandthemeparkguide.com

## What You Built

- Custom Bootstrap 5 pipeline
- Extended utility scales (`1` through `100`) for spacing, opacity, percentages, and z-index
- Project-level global styles and brand styles
- Minified JavaScript bundle
- Static public asset publishing

## Project Structure

```text
media-server/

```

## Install

```bash
npm install
```

## Build

```bash
npm run build
```

This runs:

- `clean`: removes `dist/`
- `copy:assets`: copies `public/**/*` into `dist/`
- `build:css`: compiles and minifies Sass into `dist/css/ctpg-bootstrap.min.css`
- `build:js`: minifies JS into `dist/js/ctpg-main.min.js`

## Watch CSS During Development

```bash
npm run watch:css
```

## Deploy to Cloudflare R2

Credentials are stored in `.env` (never commit this file).

```bash
npm run build
npm run deploy:r2
```

This uploads everything in `dist/` to the `ctpg-media` R2 bucket.
